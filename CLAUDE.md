## Data

`data/Survey_Results_UC.csv` — 96 respondents × 60 Likert items.

- Four blocks of 15: `T` Technology, `E` Education, `S` Ethics/Society, `V` Environment.
- Column names are the full question text prefixed with the item code (e.g. `T01. ...`).
  Parse the code from the prefix; do not rename columns by hand.
- Scale: Strongly Disagree / Disagree / Neutral / Agree / Strongly Agree / **No Comments**.
- 37 "No Comments" entries, 505 blank cells, one entirely empty row.
- File has a UTF-8 BOM on the first column name. Read with `encoding='utf-8-sig'`.

### Two properties that drive everything

1. **Acquiescence bias.** Grand mean is **+1.14** on a −2…+2 scale. Similarity on raw
   scores produces a near-complete, uninformative graph. **Row-centring is mandatory.**
2. **Uneven item informativeness.** Item SDs span 0.50–1.17. Consensus items (E15, V13,
   S09) add noise; contested items (E04, E03, E02, T08) carry the signal and are almost
   all about assessment and teaching format.

## Frozen pipeline decisions

Do not change these without the team agreeing first. Everything downstream depends on them.

| Step | Decision |
|---|---|
| Encoding | Strongly Disagree=−2, Disagree=−1, Neutral=0, Agree=1, Strongly Agree=2; "No Comments" → NaN |
| Respondent filter | Drop respondents with >12 missing items → **86 remain** |
| Imputation | Column-mean, applied after the filter |
| Centring | Row-centre: subtract each respondent's own mean across all 60 items |
| Similarity | Pearson correlation on the row-centred matrix |
| Sparsification | **Symmetrised (union) kNN, k = 4** |
| Weighting | Build weighted; binarise only for path-based metrics. Report both. |
| Nodes | Respondents (primary network); items (secondary network) |

**Do not use mutual kNN.** It fragments the graph into 38 components with 58 edges.
Union/symmetrised kNN is what produces the validated results below.

Not optional. This comparison is what the instructor means by "try different metrics."

- Cosine similarity and Gower distance instead of Pearson

## Conventions

- Python 3, pandas + numpy + networkx + scikit-learn + matplotlib. Pin in `requirements.txt`.
- **Seed every stochastic call.** Louvain, rewiring, layouts, and DW simulations all need
  fixed seeds or the report's numbers won't reproduce.
- No hardcoded absolute paths; resolve relative to the repo root.
- Figures: consistent colour map across all plots, readable at print size, captions in the
  report rather than baked into the image.
- Keep functions importable and side-effect free; `run_all.py` orchestrates.

## Do not

- **Do not claim polarisation.** PC1 explains 8.3%. The data does not support a two-camp
  story. The real finding is superficial consensus with genuine local clustering.
- **Do not report modularity without the null comparison.** kNN manufactures modularity by
  construction; the number is meaningless on its own.
- **Do not report a single threshold without the sensitivity sweep.**
- **Do not present the DW plateau at 5 clusters for small ε as a discovery.** It's partly an
  artefact of Likert data starting on a discrete 5-point grid. Say so explicitly.
- **Do not silently modify the frozen decisions above.** Flag and ask.
